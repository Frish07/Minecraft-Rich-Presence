# Minecraft Rich Presence

Клиентский Fabric-мод, отображающий игровую сессию Minecraft в Discord Rich Presence.

## Совместимость

| Minecraft | Статус | Java |
| --- | --- | --- |
| 26.3 | Целевая конфигурация; сборка не проверена в текущем окружении | 25 |
| Остальные версии | Пока не поддерживаются | — |

Совместимость не заявляется без успешной сборки и проверки запуска для конкретной версии. Для старых версий нужны отдельные проверенные адаптеры Minecraft/Fabric и упаковка Discord RPC с совместимой версией Java.

## Возможности

- Показывает версию Minecraft, одиночный/сетевой режим и длительность игровой сессии.
- Реагирует на события входа, выхода, запуска и закрытия игры — без опроса каждый тик.
- Выполняет Discord IPC в отдельном daemon-потоке и повторяет подключение после отключения Discord.
- Позволяет показывать статус Main Menu или очищать присутствие в меню.
- Работает без Discord: игра не зависает, RPC повторяет попытку в фоне.

Нужны приложение Discord Desktop и Application ID. Бот, пользовательский токен и OAuth-вход не используются.

## Установка и настройка

1. Установите Fabric Loader и Fabric API для Minecraft 26.3.
2. Поместите JAR релиза в папку `mods` и один раз запустите Minecraft.
3. Создайте приложение Discord и скопируйте его Application ID.
4. Откройте `config/minecraft-rich-presence.json`, задайте `applicationId` и перезапустите Minecraft.
5. Добавьте в приложение Discord image asset с именем из `fallbackImage` (по умолчанию `minecraft`).

При первом запуске создаётся конфигурация:

```json
{
  "applicationId": "",
  "fallbackImage": "minecraft",
  "fallbackImageText": "Minecraft",
  "showMainMenu": true,
  "mainMenuLabel": "Main Menu",
  "serverIconUrls": {}
}
```

`serverIconUrls` — явная настройка пользователя: соответствие адреса сервера общедоступному HTTPS URL изображения. Мод не отправляет адрес сервера или favicon в сервисы хостинга изображений. Современный Rich Presence API Discord принимает внешние URL изображений, но favicon Minecraft передаётся игре как байты, а не как публичный URL. Поэтому без явного сопоставления используется asset приложения Discord. Разрешены только HTTPS URL без встроенных учётных данных.

## Сборка и тесты

GitHub Actions настроен для установки JDK и Gradle и сборки объявленной матрицы, в которой сейчас только 26.3. Локальные Java и Gradle не нужны для скачивания готовых артефактов. После успешной сборки с тегом `v*` в GitHub Release публикуется только production JAR мода.

Для разработки нужны JDK 25 и Gradle 9.6; команда проверки — `gradle clean build`. Тесты проверяют форматирование состояний и безопасный fallback иконки. Перезапуск Discord и полный игровой цикл требуют отдельной проверки в запущенной игре.

Перед объявлением релиза совместимым вручную проверьте вход в Multiplayer и смену сервера, Singleplayer, возврат в главное меню, отсутствие/перезапуск Discord, серверы без favicon или с некорректным адресом и закрытие Minecraft. Для этого нужны настоящая игра и клиент Discord; такие сценарии не выдаются за автоматические unit-тесты.
